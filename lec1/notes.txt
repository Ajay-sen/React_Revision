>>why react was created?
    -React was created by Facebook in 2013 to improve the performance and maintainability of complex UIs, especially for its growing web applications like Facebook and Instagram. Traditional DOM manipulation was slow, so React introduced a virtual DOM to optimize updates efficiently. It also promoted a component-based architecture, making UI development modular and reusable. React aimed to provide a fast, scalable, and flexible way to build interactive user interfaces while improving developer productivity.

>> react is a library:
    framework VS library:
      >> Framework: Provides a complete structure with predefined rules, controlling the flow of the application (e.g., Angular, Django, nextJS). Developers follow its architecture.
      -defined naming conventions
      
        >> Library: A collection of reusable functions or components that developers call as needed (e.g., React, jQuery). The developer controls the application flow.
        Key Difference: In a framework, the framework calls the code; in a library, the code calls the library.
