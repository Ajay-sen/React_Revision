>> in this lec we will be working  on React Router
>> React Router is a standard third party library for routing in react application, it enables navigation between different views or pages by updating URL without reloading the pages

- Declarative Routing: Uses components like <Route> and <Link>.
- Dynamic Routing: Matches URL parameters dynamically.
- Nested Routes: Allows routes inside routes for better structuring.
- Programmatic Navigation: Uses useNavigate() for navigation via code.
