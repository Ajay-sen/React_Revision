>> npm vs npx:
    npm (Node Package Manager): Used to install, manage, and run packages globally or locally. Example: npm install <package>
    npx (Node Package Executor): Runs packages directly without installing them globally. Useful for executing CLI tools. Example: npx create-react-app my-app

>> npx create react app:
